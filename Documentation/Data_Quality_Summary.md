# Data Quality Summary

## Project
Telco Customer Churn Analysis

## 1. Database Validation
- Verified database tables and table structures.
- Identified primary keys and foreign key relationships.
- Validated customer ID uniqueness and completeness.
- Validated customer ZIP Code relationships with population data.

## 2. Missing Value Validation
- Checked missing values across all six tables.
- Identified missing values in relevant columns.
- Investigated blank Total Charges values.

## 3. Categorical Validation
- Checked distinct values in categorical columns.
- Reviewed available category values.

## 4. Numerical Validation
- Checked minimum, maximum, and average values.
- Reviewed numerical columns for unexpected values.

## 5. Business Rule Validation
- Checked negative tenure and charges.
- Reviewed service-related business rules.

## 6. Data Consistency Validation
- Checked Churn Value against Churn Label.
- Checked Tenure Months against Total Charges.

## Conclusion
Database validation was performed to identify data quality issues before proceeding to data cleaning and exploratory data analysis.
